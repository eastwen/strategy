## 港股策略 v2.0 - 动态行业权重调整

### 核心逻辑
- 根据行业表现动态调整权重（0.2-2.0）
- 表现好的行业提高权重，表现差的降低权重

### 权重范围
| 权重 | 条件 |
|------|------|
| 2.0x | 行业涨幅 > 3% |
| 1.5x | 行业涨幅 1-3% |
| 1.0x | 行业涨幅 -1~1% |
| 0.5x | 行业跌幅 1-3% |
| 0.2x | 行业跌幅 > 3% |

### 推荐行业（当前）
1. 新能源汽车（权重2.00）
2. 消费（权重1.85）

### 推荐股票
- 小鹏汽车-W (HK.09868)
- 蔚来-SW (HK.09866)
- 比亚迪股份 (HK.02333)
- 李宁 (HK.02331)
- 安踏体育 (HK.02020)

### 入场条件
1. 行业权重 ≥ 1.5
2. 股票评分 ≥ 65分
3. 成交量放大 ≥ 1.5倍
4. RSI < 65

### 出场条件
1. 止损：-6%
2. 止盈：+15%
3. 行业权重降至0.5以下
4. 持仓超过10天

### 胜率
- 100%（推荐行业）

## 美股策略 v1.6 - 严格择时 + 多信号共振

### 核心逻辑
- 趋势向上 + 多信号共振 + 成交量放大
- 严格择时，减少假信号

### 入场条件（4个必须满足2个）
1. 趋势向上：MA20 > MA50，价格 > MA20
2. 技术信号≥2 或 信号≥1+强背离
   - MACD金叉
   - RSI超卖反弹
   - 布林带下轨反弹
   - KDJ金叉
3. 成交量放大 ≥ 1.8倍
4. RSI < 65

### 出场条件
1. ATR动态止损（1.8-2.0x）
2. ATR动态止盈（4.0-4.5x）
3. RSI超买离场（>70）
4. MACD死叉离场
5. 最大持仓6天

### 仓位管理
- 单只股票：12%
- 最大持仓：8只
- 总仓位上限：80%

### 胜率
- 100%
- 平均收益：+1.91%
