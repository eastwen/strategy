## 🇺🇸 美股策略 1.5 优化内容

### 🔧 核心改进
1. **仓位提升**: 10% → 15%（提高收益）
2. **动态止损**: 固定4% → ATR 1.5倍（适配波动率）
3. **动态止盈**: 固定8% → ATR 3倍（2:1盈亏比）
4. **信号增强**: 加入RSI背离检测
5. **入场条件**: 需满足3个信号 或 2个信号+RSI背离

### 📈 预期效果
- **收益提升**: 15%仓位 → 收益+65%（0.55%→0.91%）
- **风险控制**: ATR动态止损更灵活
- **信号质量**: RSI背离过滤假突破

## 🇭🇰 港股策略 1.6 优化内容

### 🔧 核心改进
1. **均线优化**: 10/30 → 8/21（更快反应）
2. **突破周期**: 10日 → 8日（缩短）
3. **ADX阈值**: 15 → 12（放宽趋势要求）
4. **成交量信号**: 加入成交量金叉
5. **入场多样化**: 3种入场方案（趋势/突破/成交量）

### 📈 预期效果
- **信号增多**: 从1-2个信号→预期4-6个信号
- **盈亏比优化**: 止损3.5% → 止盈8.5%（2.4:1）
- **持仓缩短**: 8天 → 6天（更快周转）
