# 策略回测分析与优化建议

## 回测结果

### 港股标的

| 标的 | 收益率 | 最大回撤 | 夏普比率 | 交易次数 | 胜率 |
|------|--------|----------|----------|----------|------|
| 腾讯控股 | -0.13% | 0.69% | -2.92 | 3 | 33.3% |
| 阿里巴巴 | -0.17% | 0.80% | -5.25 | 9 | 33.3% |

### 问题分析

1. **胜率偏低（33.3%）**
   - 止损频繁触发，说明入场时机不够精准
   - 可能是市场整体下跌趋势导致

2. **夏普比率为负**
   - 风险调整后收益不佳
   - 波动率相对于收益过高

3. **止损被频繁触发**
   - 阿里巴巴9次交易中6次触发止损
   - 可能是入场后立即遇到调整

## 优化建议

### 1. 提高入场门槛

**当前**：得分≥70分 + 2个技术条件
**建议**：得分≥75分 + 3个技术条件

### 2. 添加趋势过滤

```python
# 只有在上升趋势中才入场
if self.ma30 > self.ma30[-5]:  # 30日线向上
    # 允许入场
```

### 3. 动态止损

**当前**：固定-6%
**建议**：
- 根据ATR（平均真实波幅）动态调整
- 入场初期止损更紧，盈利后放宽

### 4. 增加资讯/情绪过滤

**当前**：仅技术指标
**建议**：
- 加入VHSI过滤（VHSI<25才入场）
- 加入资金流向过滤

### 5. 仓位管理优化

**当前**：固定2%
**建议**：
- 根据得分动态调整：70分2%，80分3%，90分4%
- 根据市场情绪调整
