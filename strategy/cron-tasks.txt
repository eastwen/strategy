## 🚀 心跳检查系统

### 9. 策略心跳检查（每5分钟）
```bash
# 每5分钟检查一次策略状态
*/5 * * * * cd /home/admin/.openclaw/workspace-stock && source futu-venv/bin/activate && cd strategy && python3 heartbeat-check.py >> ../logs/heartbeat.log 2>&1 && deactivate
```

### 10. 心跳检查逻辑
- **静默模式**：正常状态不输出日志，减少日志量
- **问题触发**：发现问题时输出详细日志
- **机会提醒**：高评分机会≥8个时输出提醒
- **飞书通知**：发现严重问题时发送通知（待实现）
